# PDF Tamil fonts

Tamil recommendation reports need a Unicode TrueType font that ReportLab can embed.

Preferred files (SIL Open Font License):

- `NotoSansTamil-Regular.ttf`
- `NotoSansTamil-Bold.ttf`

Place those files in this folder when available. If they are absent on Windows, the PDF service uses **Nirmala UI** from `C:\Windows\Fonts\Nirmala.ttc`.
