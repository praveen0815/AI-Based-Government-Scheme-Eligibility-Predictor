# PDF report design

This is an academic research prototype. The generated PDF is a demonstration artifact. It is not government approval, certification, or a final eligibility determination.

## Purpose

An authenticated user can download a professional recommendation report for college-project demonstration. The backend generates the PDF on demand from the saved wallet so the file matches the server source of truth.

PDFs are **not stored**. They are built in memory with ReportLab and returned as `application/pdf`.

## Endpoint

`POST /api/v1/reports/recommendations`

Request:

```json
{
  "compare_scheme_ids": [],
  "language": "en"
}
```

`compare_scheme_ids` is optional. When present it must contain 2 or 3 unique CORE IDs. The report then includes a comparison section using the same comparison service as `POST /api/v1/compare`.

`language` is optional and defaults to `"en"`. `"ta"` generates the same report structure in Tamil. Eligibility is not recalculated with different rules.

Rules:

- JWT required.
- The report uses the caller's owned wallet only.
- No wallet → existing wallet 404.
- The backend reruns the existing recommendation service. Client-supplied eligibility results are ignored.
- Passwords, password hashes, JWTs, and authentication secrets are never written into the PDF.
- The profile reference is the user's display name plus the internal wallet ID. That ID is not a government identity number.

## Report contents

- Project title: State Government Sponsored Scheme Eligibility Predictor Engine Utilizing Unified Socio-Economic Data Wallets
- `AI Research Prototype` notice
- Generated date/time (UTC)
- Profile reference and socio-economic fields from the wallet
- Profile completeness percentage and missing fields, with an explicit note that completeness does not guarantee eligibility
- Recommended CORE schemes, each labeled `Predicted eligible` where applicable
- Model prediction probability and documented rule reasons
- Important catalog details and official source links
- Selected comparison schemes when requested
- Disclaimer:

> This report is generated by an academic AI research prototype using synthetic/research data and documented scheme rules. It is not government approval, certification, or a final eligibility determination. Users should verify eligibility and application requirements with the official government source.

## Frontend

Results and comparison pages expose **Download PDF Report** for signed-in users. The browser downloads `schemewise-recommendation-report.pdf`. Unauthenticated visitors are asked to sign in with a saved wallet.
